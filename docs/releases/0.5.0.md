# 0.5.0 — Factory foundation and KHEPRI explorer

Development release dated 2026-09-10.

## Included

- Existing Blender Asset Factory source and Git history through commit `29f4017`.
- Factory commands, specifications, profiles, validation/optimization tools, Three.js viewer, tests, and research.
- KHEPRI revision 4: editable Blender source, GLB, generated blueprint, five renders, and repeatable checks.
- Project main page, updated README, setup guide, and QA evidence.

## Model improvements

Consistent track interiors; sixteen seated lower rollers; connected tow brackets and pins; rear axle clearance and guards; seated hatch, radiator beds, rails, and sensor mast; cleaner side panels; a shallow airlock and attached step; a recessed belly cap eliminating overlapping rear hull surfaces.

## Verification

Blender 5.2 LTS passed 142 hull-attachment checks, track/roller checks, and GLB round-trip checks. Five full-vehicle/detail renders were inspected.

The GLB contains 451 meshes and 262,776 triangles. Source and export bounds match within the verifier's tolerance.

The original factory checkout passed its mandatory doctor gate. Its HTTP bridge probe was unavailable and its ComfyUI backend degraded. The publication checkout requires bootstrap. This release does not claim fresh-install or full factory regression validation.

## Remaining work

- KHEPRI Three.js runtime acceptance, draw-call optimization, LODs, texture baking, and animation-rig validation.
- Reconcile inherited machine-specific storage instructions before production.
- Continue the reference-first art pipeline work recorded in the preserved prior project state.

The generated blueprint is design guidance; the model does not match every inconsistent projection exactly. Optimized derivatives must remain separate from authoritative source files.
